# Euny's Life Beauty

A responsive website developed for a beauty business
serving customers in Pretoria Soshanguve.

## Features
- Responsive website design
- Beauty services and gallery
- Appointment enquiry form
- WhatsApp booking integration
- Mobile-friendly navigation

- CSS3
- JavaScript
